# OpEd Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A cross-platform desktop app that finds the OP/ED in every episode of a season by audio matching, lets the user review every cut, and writes trimmed copies with all tracks and subtitles in sync.

**Architecture:** A GUI-free core package (`oped.*`) handles discovery, fingerprinting, matching, project state, and cutting, using the ffmpeg/ffprobe CLI plus PyAV for packet-level subtitle retiming. A PySide6 GUI (`oped.gui.*`) sits on top and runs scan and export in background workers. Video uses "smart cut": each cut point is re-encoded up to the next keyframe, and everything else is stream-copied.

**Tech Stack:** Python 3.11+, uv, PySide6 ≥ 6.5 (Qt Multimedia FFmpeg backend), numpy, PyAV (`av` ≥ 12), pysubs2, platformdirs, pytest, pytest-qt. ffmpeg/ffprobe come from the user's own install.

**Spec:** `docs/superpowers/specs/2026-11-12-oped-design.md`

## Global Constraints

- Runs from source on Windows, Linux and macOS (`uv run oped`). No installers, no bundled ffmpeg.
- Original files are never modified. The only file written into the source folder is `oped-project.json` (fallback: the platformdirs user data dir).
- Output goes to the sibling folder `<Season folder> (trimmed)/` with the same file names. Ask before overwriting.
- Every cut starts `proposed`. Nothing is exported without `approved` status.
- Keep every video/audio/subtitle stream, attachments (fonts), stream language/title tags and disposition flags. Container preserved (MKV→MKV, MP4→MP4).
- Text subtitles: lines fully inside a cut are dropped, lines crossing a cut edge are clipped. Image subtitles (PGS/VobSub) are kept or dropped whole.
- Chapters are shifted. Chapters starting inside a removed segment are dropped.
- Smart-cut failure is never silently replaced: the user picks `reencode` (exact, slow) or `keyframe` (fast, may keep ~2 s).
- Episodes with no approved cuts are copied unchanged into the output folder (status "copied unchanged").
- External subtitles (`.ass .ssa .srt .vtt .sup`) are matched by name, retimed, and written next to the output under the same relative path. `Fonts/`, `fonts/` and `Attachments/` are copied as is. `.mka` produces a warning only.
- Copyrighted episodes never go in the repo or CI. Tests use synthetic media generated with ffmpeg.
- All subprocess calls use argument lists (no shell). Paths may contain spaces, brackets, apostrophes and non-ASCII characters.

## Review Focus

1. **Fansub-style filenames** (`[SubsPlease] Sousou no Frieren - 01 (1080p) [A1B2C3D4].mkv`, apostrophes, Japanese characters). Natural sort, sidecar matching, ffmpeg concat-list escaping and output naming must all work → tests in Task 2 and Task 4.
2. **Cuts touching the file edges or each other** (a cut from 0.0, a cut to the very end, overlapping or adjacent cuts). Merged and handled with no zero-length segments → tests in Task 3 and Task 6.
3. **`E1` vs `E10` sidecar ambiguity.** `E1.ass` must not attach to `E10.mkv` → test in Task 2.
4. **Re-export into an existing output folder.** The user is asked first, and a half-written file is never left under the final name (`.part` + rename) → test in Task 6.
5. **ffmpeg missing or not on PATH.** The app starts and shows a clear message with the install command for the OS, and doesn't crash → tests in Task 1 and Task 11.

### Task 3: Project model, timeline math, persistence

**Files:**
- Create: `src/oped/project.py`, `src/oped/timeline.py`, `tests/test_project.py`, `tests/test_timeline.py`

**Interfaces:**
- Consumes: `Season`, `EpisodeFiles` (Task 2).
- Produces (`project.py`):
  - `Kind = Literal["OP","ED"]`, `Status = Literal["proposed","approved","rejected"]`
  - `@dataclass Reference(id: str, kind: Kind, label: str, episode: str, start: float, end: float, confirmed: bool = True)`. `episode` is the video file name.
  - `@dataclass Cut(id: str, start: float, end: float, status: Status = "proposed", reference_id: str | None = None, confidence: float | None = None)`. `reference_id=None` means a hand-added cut.
  - `@dataclass EpisodeState(file: str, cuts: list[Cut] = [], flags: list[str] = [], scanned: bool = False)` (use `field(default_factory=list)`)
  - `@dataclass Project(folder: Path, references: list[Reference], episodes: dict[str, EpisodeState])` with `approved_intervals(file: str) -> list[tuple[float,float]]`, `to_json() -> dict` and `@classmethod from_json(folder, d) -> Project`.
  - `PROJECT_FILE = "oped-project.json"`, `SCHEMA_VERSION = 1`, `HIGH = 0.85`, `WEAK = 0.65`
  - `new_id() -> str` (uuid4 hex[:8])
  - `confidence_level(c: float | None) -> Literal["manual","high","weak","none"]`: `None` gives manual, `≥ HIGH` gives high, `≥ WEAK` gives weak, anything else gives none.
  - `project_path(folder: Path) -> Path`: `folder/PROJECT_FILE` if the folder is writable (checked by creating and deleting a temp file), else `platformdirs.user_data_dir("oped")/projects/<sha1(abs folder)>.json`.
  - `load_project(season: Season) -> Project`: loads if present, adds an `EpisodeState` for new episodes, and keeps the state of missing ones.
  - `save_project(project: Project) -> Path`: atomic write (`.tmp` + `os.replace`).
- Produces (`timeline.py`):
  - `Interval = tuple[float, float]`
  - `merge_cuts(cuts: list[Interval], duration: float) -> list[Interval]`: clamps to `[0, duration]`, sorts, merges overlapping or touching cuts (gap < 0.001 s), and drops empty ones.
  - `keep_intervals(cuts: list[Interval], duration: float) -> list[Interval]`: the complement of the merged cuts, dropping pieces shorter than 0.05 s.
  - `class TimeMap(cuts: list[Interval], duration: float)` with `out_duration: float`.
    - `map(t) -> float | None`: `None` when t falls strictly inside a cut.
    - `snap(t) -> float`: like `map`, but a time inside a cut maps to that cut's output position.
    - `map_span(a, b) -> Interval | None`: maps the kept portion of `[a,b]` as one span, or `None` if nothing is kept. Used for text subtitles.
    - `map_span_whole(a, b) -> Interval | None`: returns `None` unless ≥ 50% of `[a,b]` is outside cuts. Otherwise `start' = snap(first kept point)` and `end' = min(start' + (b-a), out_duration)`. Used for image subtitles.

### Task 4: Video and audio cutting (smart / reencode / keyframe) — includes a checkpoint on real files

**Files:**
- Create: `src/oped/cutter.py`, `tests/test_cutter.py`, `scripts/spike_cut.py`

**Interfaces:**
- Consumes: `Tools`, `MediaInfo`, `probe`, `keyframes`, `run` (Task 1); `Interval` (Task 3).
- Produces:
  - `Mode = Literal["smart","reencode","keyframe"]`
  - `class SmartCutError(Exception)`
  - `SMART_ENCODERS: dict[str, tuple[str, list[str]]] = {"h264": ("libx264", ["-crf","14","-preset","slow"]), "hevc": ("libx265", ["-crf","16","-preset","slow","-x265-params","repeat-headers=1:log-level=error"])}`
  - `cut_video(tools, info: MediaInfo, keep: list[Interval], out: Path, mode: Mode, workdir: Path) -> Path`: writes the first video stream only, to `out` (`.mkv`).
  - `cut_audio(tools, info: MediaInfo, keep: list[Interval], out: Path, workdir: Path) -> Path`: writes all audio streams, stream-copied, to `out` (`.mka`).
  - `concat_list(entries: list[tuple[Path, float | None, float | None]]) -> str`: concat-demuxer text (`file '...'` with `'` escaped as `'\''`, plus `inpoint`/`outpoint` lines).
- Algorithm (`smart`), for each keep interval `[a,b]`:
  - Let `K1` be the first keyframe `≥ a` and `K2` the last keyframe `≤ b`.
  - If `K1 >= K2`, encode `[a,b]`.
  - Otherwise, encode `[a,K1)`, stream-copy `[K1,K2)` (concat demuxer, `inpoint K1`, `outpoint K2`), and encode `[K2,b)`.
  - Encoded pieces use the `SMART_ENCODERS` entry for the source codec, with the source's `pix_fmt`, `-fps_mode passthrough` and `-an -sn`.
  - All pieces are joined with the concat demuxer (`-c copy`).
  - A codec missing from `SMART_ENCODERS` raises `SmartCutError` before any work starts.
- Validation (smart only):
  - `ffmpeg -v error -i out -f null -` must produce empty stderr.
  - The output duration must be within 0.1 s of `sum(b-a)`.
  - Any failure raises `SmartCutError`.
- `reencode`: one ffmpeg call with `trim`/`setpts` + `concat` filters, using `SMART_ENCODERS` (fallback `libx264` crf 16).
- `keyframe`: concat demuxer with `inpoint`/`outpoint` on the source and `-c copy`.
- Audio: concat demuxer on the source with per-interval `inpoint`/`outpoint`, `-map 0:a -c copy`.

### Task 8: Reference matching

**Files:**
- Create: `src/oped/matching.py`, `tests/test_matching.py`

**Interfaces:**
- Consumes: `FPS`, `features_from_pcm` (Task 7); `WEAK` (Task 3).
- Produces:
  - `@dataclass Match(start: float, end: float, confidence: float)`
  - `find_reference(ref: np.ndarray, ep: np.ndarray, fps: float = FPS) -> Match | None`. Returns `None` if `len(ep) < len(ref) // 2` or `len(ref) == 0`.
- Algorithm:
  - `score(t) = mean_i dot(ref[i], ep[t+i])`, computed via FFT cross-correlation summed over the 12 bins. Offsets may run past either end so partial overlap is allowed, normalized by the overlap length, with overlap ≥ 50% of `len(ref)`.
  - Take `t* = argmax`.
  - Per-frame similarity `s[i] = dot(ref[i], ep[t*+i])`, smoothed with a 2 s (20-frame) moving average.
  - The matched span is the longest run where smoothed `s ≥ 0.6`.
  - `confidence = mean(s over span) * min(1, span_len / (0.5 * len(ref)))`.
  - `start = (t* + span_first) / fps`, `end = (t* + span_last + 1) / fps`.

### Task 9: Reference discovery without hints

**Files:**
- Modify: `src/oped/matching.py`
- Test: `tests/test_matching.py`

**Interfaces:**
- Produces:

  - `discover_references(features: dict[str, np.ndarray], fps: float = FPS, min_len: float = 30.0) -> list[Candidate]`
- Algorithm:
  1. Downsample each feature matrix to 2 fps by averaging blocks of 5 frames and re-normalizing.
  2. For each pair of consecutive episodes (natural order, the dict's insertion order), take each region separately: the first 40% and the last 25% of each file.
